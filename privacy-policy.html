隐私政策

应用名称：NeoCoach　|　包名：com.neocoach.health
版本：v1.0　|　生效日期：2026-09-10

一、引言

本隐私政策适用于「NeoCoach」（应用包名 com.neocoach.health，以下简称"本应用"）。本应用是一款个人健康与跑步训练辅助工具，我们非常重视你的个人信息与健康数据安全。 请你在使用本应用前仔细阅读并充分理解本政策。当你点击"同意"或开始使用本应用，即表示你已同意本政策所述的信息处理方式。

二、我们收集哪些信息

1. 你主动提供的信息 性别、出生年份、身高、体重、跑步目标、每周可跑天数。这些信息用于生成个性化训练计划。 2. 你授权后从「华为运动健康」读取的信息 锻炼记录（距离、时长、配速、步频、热量）、睡眠记录与睡眠评分、静息心率与心率区间、步数、体重。仅在获得你的明确授权后读取，你可随时在系统设置中撤回授权。 3. 你在应用内的使用信息 与 AI 教练的对话内容、训练计划的完成情况、你填写的训练反馈与身体感受。 4. 设备与日志信息 应用版本号、设备型号、崩溃日志，仅用于故障排查与稳定性改进。

三、我们如何使用这些信息

· 在你的设备本地计算健康指标与趋势（恢复评分、负荷、基线对比等）； · 生成训练计划、恢复评分与教练建议； · 在你自行开启 AI 服务时，生成自然语言的教练回复； · 排查故障、修复缺陷、改进产品体验。 我们不会将你的个人信息用于广告投放，也不会用于本政策未载明的其他用途。

四、信息存储在哪里

你的健康数据、对话记录与个人设置全部存储在你本人设备的本地数据库中。 本应用没有自建服务器，我们不会将你的上述数据上传到由我们控制的任何服务器，也不会对其进行备份或留存。 你可以随时在「设置 → 数据与隐私」中清除本地数据或对话历史；卸载本应用亦可彻底移除上述数据。

五、信息共享与第三方服务

1. 大语言模型服务（可选，需你主动开启） 当你自行配置 API Key 并启用 AI 教练对话时，本应用会将经过数值化处理的健康摘要（例如距离、时长、配速、睡眠评分、静息心率等）以及你发送的提问文本，通过加密连接发送给你所选择的大语言模型服务商（当前支持 DeepSeek，由杭州深度求索人工智能基础技术研究有限公司提供）。 API Key 由你本人填写并仅保存在本机，我们无法查看、不会上传、也不会留存。若你不配置 API Key，则不会有任何数据离开你的设备。 2. 华为运动健康 经你授权后读取运动与健康数据，仅用于本机计算与展示。 3. 其他 除上述情形及法律法规的强制要求外，我们不会向任何第三方出售、出租或共享你的个人信息。

六、系统权限说明

· ohos.permission.INTERNET｜与 AI 服务通信。仅在你配置 API Key 后使用。 · ohos.permission.VIBRATE｜训练提醒与计时振动反馈。 · ohos.permission.LOCATION、ohos.permission.APPROXIMATELY_LOCATION｜户外跑步时记录轨迹与配速。 · ohos.permission.KEEP_BACKGROUND_RUNNING｜跑步过程中保持计程不中断。 · 运动健康（Health Service Kit）读取权限｜读取你授权的锻炼、睡眠与心率数据。 以上权限均在你实际使用对应功能时申请，拒绝授权不影响其他功能的使用。

七、你的权利

· 查阅与更正｜在「设置」与「个人资料」页面查看、修改你填写的信息。 · 删除｜「设置 → 数据与隐私 → 清除本地数据 / 清除对话历史」可永久删除相关记录。 · 撤回授权｜在系统「设置 → 应用 → 权限」中关闭已授予的权限。 · 联系我们｜如对本政策有任何疑问、意见或投诉，请通过下方邮箱与我们联系，我们将在 15 个工作日内答复。

八、未成年人保护

本应用不面向 14 周岁以下的儿童。若你是不满 14 周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本应用。

九、政策更新与联系方式

我们可能不时更新本隐私政策。政策更新后，我们会在应用内以显著方式公示。 若更新涉及你权利的重大调整，我们会在你下次启动应用时以弹窗形式重新征求你的同意。
