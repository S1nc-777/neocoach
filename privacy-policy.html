隐私政策

应用名称：NeoCoach　|　包名：com.neocoach.health
版本：v1.0　|　生效日期：2026-09-10

一、引言

本隐私政策适用于「NeoCoach」（应用包名 com.neocoach.health，以下简称"本应用"）。本应用是一款个人健康与跑步训练辅助工具，我们非常重视你的个人信息与健康数据安全。 请你在使用本应用前仔细阅读并充分理解本政策。当你点击"同意"或开始使用本应用，即表示你已同意本政策所述的信息处理方式。

二、我们收集哪些信息

1. 你主动填写的信息 年龄、性别、身高、体重、静息心率、最大心率、跑步目标、每周可跑天数。这些信息用于计算训练强度区间、恢复评分与个性化训练计划。 2. 你授权后从「华为运动健康」读取的信息 锻炼记录（距离、时长、配速、步频、热量）、睡眠记录与睡眠评分、静息心率与心率区间、步数、体重。仅在获得你的明确授权后读取，你可随时在系统设置中撤回授权。 3. 你在应用内的使用信息 与 AI 教练的对话内容、训练计划的完成情况、你填写的训练反馈与身体感受、饮食记录。 4. 位置信息 当你主动开始「跑步追踪」功能时，本应用通过系统定位服务采集你的位置，用于绘制跑步轨迹、计算距离与配速。你可以不使用该功能，也可随时在系统设置中关闭定位权限。 5. 你拍摄或选择的食物照片 当你主动使用「拍照识别食物」功能时，本应用会读取你选中的那一张图片，用于识别食物种类与估算营养成分。 6. 你自行填写的第三方服务密钥 你为 AI 教练或联网搜索填写的 API Key，仅保存在你的设备本地私有存储，用于向对应服务发起请求。 本应用不收集设备型号，也不接入任何统计或崩溃上报服务 —— 我们没有服务器。

三、我们如何使用这些信息

· 在你的设备本地计算健康指标与趋势（恢复评分、负荷、基线对比等）； · 生成训练计划、恢复评分与教练建议； · 在你自行开启 AI 服务时，生成自然语言的教练回复； · 排查故障、修复缺陷、改进产品体验。 我们不会将你的个人信息用于广告投放，也不会用于本政策未载明的其他用途。

四、信息存储在哪里

你的健康数据、饮食记录、对话记录与个人设置全部存储在你本人设备的本地数据库中。 本应用没有自建服务器，我们不会将你的上述数据上传到由我们控制的任何服务器，也不会对其进行备份或留存。 你可以随时在「设置 → 数据与隐私」中清除本地数据或对话历史；卸载本应用亦可彻底移除上述数据。

五、信息共享与第三方服务

本应用不向任何第三方出售你的个人信息。仅在下列情形，且由你主动配置并启用相应功能时，才会发生数据传输： 1. 大语言模型服务商（AI 教练对话） · 杭州深度求索人工智能基础技术研究有限公司（api.deepseek.com） · 硅基流动 SiliconFlow（api.siliconflow.cn） 传输内容：经过数值化处理的健康摘要（例如距离、时长、配速、睡眠评分、静息心率等）、你发送的提问文本，以及你在使用「拍照识别食物」时选中的照片。 传输目的：生成 AI 教练回复、识别食物营养成分。前提：由你自行配置对应服务商的 API Key 并主动发起。 2. 联网搜索服务商（教学资源检索） · 北京智谱华章科技有限公司（open.bigmodel.cn） 传输内容：你发送的提问文本。 传输目的：检索与跑步教学相关的网页链接。前提：由你在「设置」中自行配置联网搜索 Key，且你的提问属于教学/资源检索类。 3. 华为运动健康 经你授权后在本机读取运动与健康数据，数据不离开你的设备。 4. 关于密钥 你在本机填写的 API Key 仅保存在设备本地私有存储，我们无法查看、不会上传、也不会留存。若你不配置任何 Key，则不会有任何数据离开你的设备。 请你知悉：上述第三方服务商对信息的处理受其自身隐私政策约束，建议你在使用前查阅其隐私政策。 除上述情形及法律法规的强制要求外，我们不会向任何第三方出售、出租或共享你的个人信息。

六、系统权限说明

· ohos.permission.INTERNET｜与 AI 服务通信。仅在你配置 API Key 后使用。 · ohos.permission.VIBRATE｜训练提醒与计时振动反馈。 · ohos.permission.LOCATION、ohos.permission.APPROXIMATELY_LOCATION｜户外跑步时记录轨迹与配速。 · ohos.permission.KEEP_BACKGROUND_RUNNING｜跑步过程中保持计程不中断。 · 运动健康（Health Service Kit）读取权限｜读取你授权的锻炼、睡眠与心率数据。 · 相册（系统图片选择器）｜仅当你主动使用「拍照识别食物」时，读取你选中的那一张图片。 以上权限均在你实际使用对应功能时申请，拒绝授权不影响其他功能的使用。

七、敏感个人信息特别说明

健康与运动数据（心率、心率变异性、血氧、压力、睡眠、体重、血压、体温、锻炼记录）属于敏感个人信息。我们仅在获得你的单独授权后读取，且仅在你本人设备的本地数据库中处理与保存，不用于任何其他目的。 位置信息同属敏感个人信息，仅在你主动开始「跑步追踪」时采集。 你可以拒绝或随时撤回上述授权，撤回不影响其他功能的使用。

八、你的权利

本应用无需注册账号即可使用，因此不涉及账户注册、登录与注销。你的权利包括： · 查阅与更正｜在「设置」与「个人资料」页面查看、修改你填写的信息。 · 删除｜「设置 → 数据与隐私 → 清除本地数据 / 清除对话历史」可永久删除相关记录。 · 撤回授权｜在系统「设置 → 应用 → 权限」中关闭已授予的权限。 · 联系我们｜如对本政策有任何疑问、意见或投诉，请通过下方邮箱与我们联系，我们将在 15 个工作日内答复。

九、未成年人保护

本应用不面向 14 周岁以下的儿童。若你是不满 14 周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本应用。

十、政策更新与联系方式

我们可能不时更新本隐私政策。政策更新后，我们会在应用内以显著方式公示。 若更新涉及你权利的重大调整，我们会在你下次启动应用时以弹窗形式重新征求你的同意。
